# 微短剧合规自检（micro-drama-compliance）

对照微短剧内容审核要点,自动检查剧本与成片合规风险并给出修改建议。

## 关于本项目

本项目由 **Mojinge（墨金格）** 团队维护,是该技能在 GitHub 的开源镜像。

- 主站(墨金格 AI 短剧工厂):https://www.mojinge.cloud/?utm_source=github_skills&utm_medium=readme&utm_campaign=interlink
- 配套工具 ShotLock(分镜连续性校验引擎):https://github.com/nianjiang888/shotlock
